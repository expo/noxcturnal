'noxcturnal': patch
---

Preserve numeric fragment values, including negative zero and nonfinite numbers, and keep every part of a composite template. Editor replacements follow global and sticky regular expressions, advance a Unicode empty match by a code point, and expand an empty named-capture token. A leading line comment that would split return, throw, or yield from its operand is inserted as a block comment; a line comment stays a line comment only when the operand already begins a line. Program insertion keeps a directive or unterminated statement from attaching to the new statement, adding an empty statement when that is what preserves the split. Raw editor text is still inserted unchanged. Invalid edit offsets are rejected before encoding, and each edit string is encoded on its own so surrogate halves cannot merge across entries.
