- Terminate lowered Flow enum declarations so following statements cannot merge with their runtime initializer, by [@kitten](https://github.com/kitten) (See [#88](https://github.com/expo/noxcturnal/pull/88))

- Reduce native materialization work by reusing syntax-selection AST counts, resolving child roles only when requested, skipping initial cache invalidation, and collecting binding references in shared storage, by [@kitten](https://github.com/kitten) (See [#81](https://github.com/expo/noxcturnal/pull/81))
- Recognize parenthesized static callee roots in `calleePath` and `calleeGlobal` fields and predicates, consistent with static member paths. Child selectors continue to follow immediate AST relationships, by [@kitten](https://github.com/kitten) (See [#91](https://github.com/expo/noxcturnal/pull/91))
- Compile phase permissions, plugin order, and artifact requirements once, and lazily bind visitor handlers while sharing runtime helpers across files, by [@kitten](https://github.com/kitten) (See [#84](https://github.com/expo/noxcturnal/pull/84))
- Evaluate custom React Refresh factories at component creation and keep generated HOC temporaries inside parameter defaults, preserving local factory bindings and independent signatures across calls, by [@kitten](https://github.com/kitten) (See [#89](https://github.com/expo/noxcturnal/pull/89))
- Keep React Refresh signatures inside single control-flow bodies and attach signatures in for initializers without native insertion failures or changing inferred function names, by [@kitten](https://github.com/kitten) (See [#88](https://github.com/expo/noxcturnal/pull/88))
- Remove obsolete event-driven child-cache seeding now that child hydration uses native packed graphs exclusively, by [@kitten](https://github.com/kitten) (See [#87](https://github.com/expo/noxcturnal/pull/87))
- Reuse route-handler scratch state across synchronous transforms, while isolating reentrant transforms and clearing per-file bindings on every exit, by [@kitten](https://github.com/kitten) (See [#85](https://github.com/expo/noxcturnal/pull/85))
- Reduce scope and binding lookup allocations by sharing immutable facts, compacting visibility and ownership transport, and avoiding reference hydration for presence checks, by [@kitten](https://github.com/kitten) (See [#83](https://github.com/expo/noxcturnal/pull/83))
- Reuse compiled native routing manifests across files for immutable prepared plans while preserving fresh validation of raw buffers and independent session lifetimes, by [@kitten](https://github.com/kitten) (See [#79](https://github.com/expo/noxcturnal/pull/79))
- Reduce source-map rendering work at edit commits and when mapping relocated source fragments, preserving map-only changes and Unicode positions, by [@kitten](https://github.com/kitten) (See [#77](https://github.com/expo/noxcturnal/pull/77))
- Reduce visitor replay allocations with sparse node caches, depth-bounded exit tracking, shared nested replay state, and leaner retained event packing, by [@kitten](https://github.com/kitten) (See [#78](https://github.com/expo/noxcturnal/pull/78))

- Update the embedded Hermes parser and expand native Flow support, including readonly properties, variance, async components, and records. Preserve detailed Flow fallback diagnostics, by [@kitten](https://github.com/kitten) (See [#37](https://github.com/expo/noxcturnal/pull/37))

## 0.1.2

### Patch Changes

- ⚠️ Fix async lowering to preserve transform selection, for-await labels, method parameter rejection timing and bindings, strictness, lexical captures, and super references. Iterator-result validation now follows generated bindings instead of source-name prefixes. Pin these repairs in a repository-owned Oxc transformer patch, by [@kitten](https://github.com/kitten) (See [#23](https://github.com/expo/noxcturnal/pull/23))
- Preserve logical-assignment receivers across private getter effects and regexp allocations. Allocate private temporaries without capturing external bindings, and finish selected nullish lowering in the same phase as private logical assignment, by [@kitten](https://github.com/kitten) (See [#20](https://github.com/expo/noxcturnal/pull/20))
- Preserve React Compiler diagnostic thresholds and continue later transforms exactly once, retaining helpers and Refresh registrations. Honor escaped directive boundaries and source-file memo-cache invalidation. Fix Refresh signatures for generated nodes and lexical blocks, reset comments, and complete configured callback paths, by [@kitten](https://github.com/kitten) (See [#27](https://github.com/expo/noxcturnal/pull/27))
- Remove the optional `maxNativeMemoryBytes` and `maxFollowUpBatches` transform settings and their session enforcement. Native sessions continue to close at phase and transform lifecycle boundaries, by [@kitten](https://github.com/kitten) (See [#10](https://github.com/expo/noxcturnal/pull/10))
- Preserve optional-chain method receivers across mutation, keep parameter temporaries local to each invocation, and honor grouped delete/call references and mandatory operations. Calling the result of an optional call no longer supplies an unrelated receiver, by [@kitten](https://github.com/kitten) (See [#21](https://github.com/expo/noxcturnal/pull/21))
- Repair public scope rename, UID allocation, scope ownership, and declaration insertion. Generated names account for decoded identifier escapes, valid Unicode rename targets are accepted, and every declaration and reference in a binding is renamed without rewriting property keys or module interfaces. Owned scopes stay distinct from containing scopes, scope parents come from the scope parent table, and global binding references include their semantic flags. Scope insertion uses retained scope coordinates instead of optional body fields, wraps concise arrows and unbraced loop bodies once, and keeps class and switch insertions on a statement list that can actually host them, by [@kitten](https://github.com/kitten) (See [#31](https://github.com/expo/noxcturnal/pull/31))
- ⚠️ Fix class lowering to preserve private identities, initialization and lexical environments, computed keys, optional calls, and strict super references across assignments and suspension. Correct TypeScript parameter-property initialization after conditional or try-wrapped super calls, by [@kitten](https://github.com/kitten) (See [#17](https://github.com/expo/noxcturnal/pull/17))
- Validate invalid input consistently across native, visitor, optimization, and empty pipelines, reporting typed syntax errors with source locations. Preserve pristine bailouts for unsupported mutable namespace exports and the documented Flow and escaped-regexp-name parser boundaries.
  Align filename/declaration classification, leading Flow comment recognition, adapter output grammar, missing selected-adapter errors, and read-only source hints. Fragment factories now enforce one complete expression and reject self-contained early errors while allowing unresolved enclosing bindings.
  Scope-free and empty pipelines now perform lightweight early-error validation without retaining an AST-node index; this adds validation work to routes that previously accepted invalid source, by [@kitten](https://github.com/kitten) (See [#28](https://github.com/expo/noxcturnal/pull/28))
- Preserve labeled exits and static-block environments when extracting captured loops. Avoid decoding external generator return values as internal loop records, reserve external names during block-scoping lowering, and resolve private writes in the correct class environment, by [@kitten](https://github.com/kitten) (See [#5](https://github.com/expo/noxcturnal/pull/5))
- Preserve numeric fragment values, including negative zero and nonfinite numbers, and keep every part of a composite template. Editor replacements follow global and sticky regular expressions, advance a Unicode empty match by a code point, and expand an empty named-capture token. A leading line comment that would split return, throw, or yield from its operand is inserted as a block comment; a line comment stays a line comment only when the operand already begins a line. Program insertion keeps a directive or unterminated statement from attaching to the new statement, adding an empty statement when that is what preserves the split. Raw editor text is still inserted unchanged. Invalid edit offsets are rejected before encoding, and each edit string is encoded on its own so surrogate halves cannot merge across entries, by [@kitten](https://github.com/kitten) (See [#32](https://github.com/expo/noxcturnal/pull/32))
- Lower for-of loops with Babel's standard createForOfIteratorHelper in inline and runtime modes. Preserve complete label chains and collision-free generated bindings while removing custom iterator dispatch, validation, and Symbol-binding rewrites. Adopt Babel's iterator lookup and cleanup semantics; inline helpers bail out with pristine input when root bindings shadow required globals, by [@kitten](https://github.com/kitten) (See [#6](https://github.com/expo/noxcturnal/pull/6))
- ⚠️ Fix legacy decorator ordering and accessor parameter metadata, and lower decorators on rest parameters. Keep private member expressions in their declaring class while preserving class replacement and constructor decoration. Generate valid, collision-free auto-accessor backing fields and retain the original static storage across class replacement and repeated class evaluations, by [@kitten](https://github.com/kitten) (See [#22](https://github.com/expo/noxcturnal/pull/22))
- ⚠️ Fix block-scoping transforms hanging on function-local bindings in loop headers and iterables.
  Preserve captured loop bindings across initializers, conditions, updates, and `finally` blocks, including `const` assignment errors, function-scoped `var` declarations, and enclosing `arguments` references in generators. Avoid unnecessary loop helpers and retain safe iteration-local declarations to preserve generated-code performance, by [@kitten](https://github.com/kitten) (See [#3](https://github.com/expo/noxcturnal/pull/3))
- `path.matchesPattern()` returns false for nodes that are not a static or computed member chain. That includes a `super()` callee, a spread argument, and an identifier reached through a `memberPath` declaration such as an `Expression` callee. Identifiers still require a declared `name` to match their own name, and static or computed members still require a declared `memberPath`. Calling it without the declaration that applies to that node throws, by [@kitten](https://github.com/kitten) (See [#36](https://github.com/expo/noxcturnal/pull/36))
- Preserve plugin cleanup failures and clean every prepared state once, including unsupported-input bailouts. Keep editor and metadata ownership separate for same-name plugin definitions, store special metadata keys as own properties, and compare keyed intents against their registration source and phase occurrence. Reject duplicate plugin definitions within one phase before lifecycle hooks run; reuse across phases remains supported, by [@kitten](https://github.com/kitten) (See [#34](https://github.com/expo/noxcturnal/pull/34))
- Preserve regexp token contexts, scoped flags, Unicode atom boundaries, case-folded set operations, string alternatives, and named capture metadata during lowering. Correct property/class complements and surrogate membership while retaining documented parser and Babel-helper compatibility boundaries, by [@kitten](https://github.com/kitten) (See [#8](https://github.com/expo/noxcturnal/pull/8))
- Load the published ESM entry by defining `require` and `__dirname` from `import.meta.url` before native initialization. CommonJS loading is unchanged. A missing colocated addon still falls back to the optional native package, and a missing package still throws, by [@kitten](https://github.com/kitten) (See [#11](https://github.com/expo/noxcturnal/pull/11))
- Preserve parameter environments, generator initialization timing and destructuring order. Unify object-rest lowering across option modes, preserve loop-head scopes and binding kinds, keep static-block temporaries local, and copy array rest values without invoking source slice or species hooks, by [@kitten](https://github.com/kitten) (See [#14](https://github.com/expo/noxcturnal/pull/14))
- Preserve JavaScript values as they cross native transport. Constant fields, queries, and direct and retained predicates carry an explicit kind, so negative zero, non-finite numbers, null, and numeric-looking strings stay distinct. Lone surrogates and other strings Rust UTF-8 cannot hold use a NUL-prefixed JSON form; ordinary strings pass through unchanged. Query globals and plugin metadata keep `__proto__` as an own enumerable data property, by [@kitten](https://github.com/kitten) (See [#35](https://github.com/expo/noxcturnal/pull/35))
- Preserve custom JSX factory and fragment imports through TypeScript prepasses, remove unused forward alias dependencies without evaluating their modules, and retain enum initializer effects during downstream tree shaking, by [@kitten](https://github.com/kitten) (See [#24](https://github.com/expo/noxcturnal/pull/24))
- Honor `comments: false` for HTML-style JavaScript comments in scripts, including native transform phases that would otherwise return unchanged input, by [@kitten](https://github.com/kitten) (See [#12](https://github.com/expo/noxcturnal/pull/12))
- Honor JSX configuration and Babel comment directive precedence, reject invalid pragmas and conflicting runtime settings, and accept escaped identifier paths. Match Babel text normalization and classic literal-spread prototypes. Preserve original development filenames and JavaScript source locations, omit unsafe automatic fragment receiver metadata, and infer index-file component names from their directory, by [@kitten](https://github.com/kitten) (See [#26](https://github.com/expo/noxcturnal/pull/26))
- Preserve references, function names, hoisted bindings, script globals, eval visibility, and dynamic writes during optimization. Correct JavaScript number formatting and exponentiation special values, and leave isolated-surrogate string expressions unfolded rather than misinterpreting their encoded representation, by [@kitten](https://github.com/kitten) (See [#7](https://github.com/expo/noxcturnal/pull/7))
- Preserve strict object spread semantics when `useBuiltIns` is enabled. Restrict classic JSX props completion to calls originating from JSX elements, so composed transforms cannot apply assignment semantics to ordinary object arguments, by [@kitten](https://github.com/kitten) (See [#9](https://github.com/expo/noxcturnal/pull/9))
- ⚠️ Fix visitor planning and dispatch so nested contracts retain their declared data, aggregate aliases classify function/class instances, widening delivers each matching route once, and skip/stop apply across a plugin's routes. Preserve nested plugin ownership and snapshot ancestry exclusions.
  Keep cache keys distinct for signed zero, nonfinite values, sparse arrays, and plugin query contracts; options rebinding uses the frozen definition. Mutable query requests refresh cached facts and each plugin must declare its query categories. Unknown enabled native options now throw.
  Match static member chains using declared native facts: request `memberPath` for members or `name` for identifiers, including child contracts. Literal dots and backslashes in property names are escaped in `memberPath` strings, leaving ordinary dotted paths unchanged. Matching without the required declaration now throws.
  Reduce member matching, query permission checks, and cache-key encoding overhead while preserving the declared contracts and mutable-request checks.
  Remove JavaScript source parsing and its prefix caches. Native AST predicates share member prefixes; explicit full-path fields retain their output-size cost. Gather validation allocation statistics during scope-free collection, and reuse the checked semantic graph for DCE-only native phases.
  Move source classification, adapter hints, locations, editor searches and whitespace operations, and insertion boundaries to Rust. Generate UIDs from decoded native AST identifier names, ignoring comment/string text and reserving names for the immutable session. Identifier validation also uses Oxc. Editor regex searches execute natively with ECMAScript syntax and UTF-16 offsets, by [@kitten](https://github.com/kitten) (See [#29](https://github.com/expo/noxcturnal/pull/29))
- Preserve sparse source-map anchors, unmapped regions, original symbol names, and explicit fragment mapping policies when composing transforms. Correct visitor locations, function-map frames, and declaration metadata for all JavaScript line terminators and Unicode header trivia, by [@kitten](https://github.com/kitten) (See [#33](https://github.com/expo/noxcturnal/pull/33))
- Preserve exponentiation assignment receivers across computed-key effects and isolate generated temporaries during recursive parameter default evaluation. Keep RegExp property keys as a single object during coercion, by [@kitten](https://github.com/kitten) (See [#19](https://github.com/expo/noxcturnal/pull/19))
- Preserve helper bindings and intrinsic dependencies, emit adapter imports in ES modules, and retain directives, hashbangs, and source maps when inserting inline helpers.
